# Русский Маяк

Официальный сайт музыкальной группы «Русский Маяк»: музыка, новости, поездки, афиша и благотворительные сборы.

Сайт свёрстан как многостраничный проект с акцентом на SEO и админку, из которой редактируется весь публичный контент. Те же данные отдаются через JSON API.

---

## Стек

- **Backend:** Laravel 13, PHP 8.3+, PostgreSQL
- **Админка:** Filament
- **Frontend:** Blade, Vite, Sass, GSAP, Lenis, Swiper
- **Прочее:** Redis, очереди, динамические sitemap и robots

---

## Что сделано

- Главная с плеером, альбомами, видео, фото, новостями, сборами и формой обратной связи
- Разделы: дискография, видеогалерея, фоторепортажи, новости, афиша, отчёты
- CMS: альбомы и треки, медиа, новости, концерты, партнёры, реквизиты, SEO
- Публичное API v1 для сайта и будущих клиентов
- Open Graph, Schema.org, ЧПУ, 301 со старых HTML-адресов
- Режим разработки с `noindex`, пока сайт не готов к индексации
